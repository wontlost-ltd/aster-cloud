# 在编辑器中使用领域词汇

**领域词汇**把团队常用的词映射到策略中的规范名。德语团队可以写 `Fahrer` 和 `alter`，编译后的策略里则是 `Driver` 和 `age`。术语在[领域词汇](/domain-vocabularies)页面维护，编辑器在你编写时使用它们。

用词汇术语编写属于语言本身：任何人都可以保存、编译和执行用到术语的策略。添加和修改术语需要包含自定义词汇的套餐（Free 以外的所有套餐）。编辑器里的**词汇**标签页和**词汇规范预览**属于[结构化编写](/docs/guides/structured-authoring-admin)。

## 术语与角色

每个术语有一个本地化名称（可附别名）、一个规范名和一个角色：

| 角色 | 在词汇标签页中的分组 | 说明 |
|---|---|---|
| 结构体 | 类型 | 类型名，例如 `Fahrer` → `Driver` |
| 字段 | 字段 | 属于某个结构体：`Driver` 的 `alter` → `age` |
| 枚举值 | 枚举成员 | 属于某个枚举 |
| 函数 | 函数 | 规则名 |
| 字面量 | 字面量 | 编译器会把这个词替换为一个文本值 |

一个词按它在源码中**所处的位置**解析，而不是全文查找替换。`Fahrer` 出现在类型位置时解析为结构体 `Driver`；作为参数名的 `fahrer` 仍是 `fahrer`。字段按它所属的结构体解析，所以同一个本地化字段名在不同结构体里可以对应不同字段。源码自己声明的名字（参数、`Let` 名称等）永远不会被改写。

示例中的术语：`Fahrer` → `Driver`（结构体）、`alter` → `age`（`Driver` 的字段）、`zugelassen` → `eligible`（函数）：

```
Modul versicherung.

Definiere Fahrer mit alter als Ganzzahl.

Regel zugelassen gegeben fahrer als Fahrer, liefert Boolesch:
  wenn fahrer.alter mindestens 18:
    gib zurueck wahr.
  gib zurueck falsch.
```

编译后的策略有结构体 `Driver`（字段 `age`）和规则 `eligible`；参数仍叫 `fahrer`。

## 一条策略用到哪些术语

一条策略并不会用到你的全部术语。对每组术语（一个领域加一种语言），编辑器、保存检查、审批和执行都按同一条规则判断：

- 该组的语言与策略的语言一致（策略语言由关键词决定，按主语言比较，所以 `de` 适用于 `de-DE` 策略）；并且
- 该组至少有一个本地化名称或别名作为完整的词出现在代码中。注释和引号内的文字不算。

**团队策略**使用团队词汇和作者的个人词汇。同一个写法在两边映射到不同规范名时，以团队术语为准，编辑器会提示哪些个人术语未生效。

## 保存、审批与快照

- **保存**时按与编辑器相同的规则选取你当前的术语来编译策略。编译不通过的保存会被拒绝，并给出诊断。
- **审批**时把该版本用到的术语冻结为词汇快照，附在这个版本上。
- 已批准版本**执行**时使用它的快照。之后修改或删除术语，不会改变已批准版本的含义；要采用新的术语，请保存并审批一个新版本。

## 词汇标签页

有结构化编写能力时，编辑器侧栏有一个**词汇**标签页：

- 列出这条策略作用域内的术语，按角色分组（类型、按所属结构体分组的字段、函数、枚举成员、字面量）。
- **搜索术语**同时匹配本地化名称和规范名。
- 点击术语即在光标处插入它的本地化写法；有选中文字时替换选区。
- **把选中文字加为术语**打开与领域词汇页面相同的对话框，并预填选中的文字。团队策略里新术语写入团队词汇，否则写入你的个人词汇。能否添加术语取决于你的套餐。
- **管理词汇**打开领域词汇页面。

命令面板（**Ctrl+K** 或 **⌘K**）里有**打开词汇标签页**。

## 词汇规范预览

词汇规范预览把策略中每个词汇术语换成规范名，把每个字面量术语换成它代表的文本值，关键词和其余文字保持原样。对上面的示例，源码写 `Fahrer`、`alter`、`zugelassen` 的地方，预览显示 `Driver`、`age`、`eligible`。

- 在词汇标签页顶部点击**显示词汇规范预览**，或在命令面板里选**切换词汇规范预览**。预览在宽屏下显示在编辑器下方。
- 预览只读，不保存，也不参与编译，只用来帮助你和评审者阅读策略。
- 预览跟随光标：光标落在术语上时，预览选中对应的规范名。
- 不可见字符与双向控制字符（例如 U+202E）显示为可见的占位符，窗格会列出它们的码位，因此无法打乱文字的显示顺序。
- 无法生成预览时，窗格会提示，并在你下次修改后重试；编辑器照常可用。

预览需要编辑器的语言服务器支持。在编辑器中把鼠标悬停在术语上，也会显示写法与对应的规范名。
